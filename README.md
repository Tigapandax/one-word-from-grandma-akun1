**Roboot**

The single word my grandma would text about AI. She means "robot", types one extra "o", and the joke lands in one word — warm, a little baffled, and unmistakably about a machine.

## Run it

```sh
node main.ts
```

Writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
